# Menu-Driven Calculator 🧮

A simple, console-based calculator built using **Core Java**. This program allows users to perform basic arithmetic operations through an interactive menu.

## 🚀 Features

- Addition of two numbers.
- Subtraction of two numbers.
- Multiplication of two numbers.
- Division of two numbers.
- Handles division by zero.
- Interactive menu that runs until the user chooses to exit.
- Displays an error message for invalid menu choices.

## 🛠️ Technologies Used

- Java
- Scanner Class
- Switch Statement

## 📚 Java Concepts Practised

- Variables and Data Types
- User Input using `Scanner`

- Conditional Statements (`if-else`)
- Switch Statement
- Arithmetic Operators
- Type Casting
- Break Statement

## ▶️ How to Run

1. Clone this repository or download the project.
2. Open the Calculator folder in VS Code or any Java IDE.
3. Compile the Java file:

   ```bash
   javac Calculator.java
   ```

4. Run the program:

   ```bash
   java Calculator
   ```
