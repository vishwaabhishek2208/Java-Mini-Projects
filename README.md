## How to Run

Each project folder has its own README with instructions.

### Quick start

```bash
# 1. Clone the repo
git clone https://github.com/vishwaabhishek2208/Java-Mini-Projects.git
cd Java-Mini-Projects

# 2. Run the Basic Calculator
cd Basic-Calculator
javac Calculator.java
java Calculator
