# Daily Expense Detective 💰

A beginner-friendly, console-based expense tracker built using **Core Java**. This project helps users manage their daily budget, record multiple expenses, calculate total spending, and check their remaining budget.

## 🚀 Features

- Enter and validate a daily budget.
- Add multiple expenses.
- Reject negative expense amounts.
- Store expenses using Java `ArrayList`.
- Calculate total expenses.
- Check whether the budget has been exceeded.
- Display the remaining budget.

## 🛠️ Technologies Used

- Java
- Java Collections Framework
- ArrayList
- Scanner Class

## 📚 Java Concepts Practised

- Variables and Data Types
- Conditional Statements (`if-else`)
- Loops (`while`, `for-each`)
- User Input using `Scanner`
- ArrayList
- Basic Input Validation

## ▶️ How to Run

1. Clone this repository or download the project.
2. Open the project folder in VS Code or any Java IDE.
3. Compile the Java file:

   ```bash
   javac Menu.java
   ```

4. Run the program:

   ```bash
   java Menu
   ```
