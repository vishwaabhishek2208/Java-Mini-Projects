# 💰 Daily Expense Detective

A beginner-friendly, console-based Java application that helps users track their daily expenses, calculate total spending, and monitor their daily budget.

This is my first Java mini project, built while learning Core Java and the Java Collections Framework.

## ✨ Features

- Enter and validate a daily budget.
- Add multiple expenses.
- Stop entering expenses by entering `0`.
- Validate negative expense amounts.
- Store expenses using `ArrayList`.
- Display all recorded expenses.
- Count the total number of expenses.
- Calculate total expenses.
- Find the largest expense.
- Calculate the remaining budget.
- Detect and display budget overspending.
- Handle cases where no expenses are recorded.

## ▶️ How to Run

**1. Clone the repository**

```bash
git clone YOUR_REPOSITORY_URL
```

**2. Navigate to the project folder**

```bash
cd Daily-Expense-Detective
```

**3. Compile the Java file**

```bash
javac Menu.java
```

**4. Run the application**

```bash
java Menu
```
